# Public compatibility checklist

- Classify source, binary/package, behavioral, and persisted-state compatibility.
- Update emitted declaration reports for intentional signature changes.
- Cover runtime observability and compile-time assignability.
- Preserve controlled proposal/acceptance and callback ordering.
- Review event names, diagnostic codes, identity, cancellation, and selector fan-out.
- Add fixtures or ordered migrations for persisted-state changes.
- Synchronize guides, references, checked examples, READMEs, and coverage metadata.
- Verify packed consumers and the complete release gate.
