# `@stages/core` exports

This page is an inventory of the package entry point. It is normative for
export availability; linked reference pages define behavior in detail.

**For:** consumers looking up an API symbol and maintainers checking coverage.  
**Prerequisites:** none. For usage, start with [First controller](/start/first-controller).

Last reviewed against `packages/core/src/index.ts`: **2026-09-03**.

| Area | Exports |

## Type exports

| Area | Exports |

| Events, reduction, transforms | [`StagesEventSource`, `StagesEvent`, `StagesEventTarget`, `StagesEventInit`](/reference/core/event-types), [`StagesPatch`](/reference/core/path-utilities#stagespatch), [`FieldReduceContext`, `FieldReduceResult`, `FieldEventReducer`](/reference/core/field-types#reducer-types), [`TransformContext`, `TransformConfig`](/reference/core/event-types#transform-types) |

| Schema | [`FieldNodeConfig`, `GroupNodeConfig`, `CollectionVariantConfig`, `CollectionNodeConfig`, `StageNodeConfig`, `WizardNavigationConfig`, `WizardNodeConfig`, `NodeConfig`, `StagesSchema`, `StagesSchemaFactory`, `StagesSchemaInput`, `NormalizedNode`, `NormalizedBranch`, `EvaluatedSchema`](/reference/core/schema-types), [`EvaluateSchemaOptions`](/reference/core/schema-utilities#evaluateschema) |
| Snapshots and controller | `FieldSnapshot`, `ContainerSnapshot`, `RenderNodeSnapshot`, `StagesSnapshot`, `StagesChange`, [`StagesOptions`](/reference/core/controller#stagesoptions), [`StagesUpdate`](/reference/core/controller#update), [`StagesController`](/reference/core/controller#stagescontroller) |

| Persistence | `SerializedStagesState`, `StagesValueCodec`, `StagesExtensionCodec`, `StagesStateMigration` |

`NormalizedNode`, `NormalizedBranch`, `EvaluatedSchema`, and
`EvaluateSchemaOptions` primarily serve schema tooling and adapter/tool authors.
Ordinary controller consumers should prefer readonly render snapshots.

The machine-readable [coverage manifest](/feature-coverage) is checked against
this entry point so a new export cannot be added silently.
