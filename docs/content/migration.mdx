# Migrating from 0.x

<Callout emoji="⚠️">
  Stages v1 is intentionally not API-compatible with the `react-stages` 0.x
  package. Migrate one controlled surface at a time.
</Callout>

The central changes are:

- `Form` and `Stages` render props become a framework-neutral controller plus
  an adapter.
- Dot-string paths become safe segment arrays.
- `data` becomes the application-owned `value`.
- Field-local parsing moves to registry reducers.
- Computed and cross-field behavior becomes ordered transforms returning
  explicit patches.
- Validation execution (`on`) is separate from presentation (`revealOn`).
- Collections and wizard navigation become named node events.
- Durable interaction state uses versioned serialization and migrations.

Keep 0.x and v1 imports side by side during migration. Establish the controlled
handshake first, then migrate fields, validation, transforms, structural nodes,
and finally serialization. Remove `react-stages` only after no route imports it.

The complete mapping—including every public 0.x root export and processing
pattern—is in the repository
[migration guide](https://github.com/unic/stages/blob/master/docs/MIGRATING_TO_V1.md).
