# Schemas and recursive nesting

For the expanded conceptual guide and exact declarations, see
[Schemas](/core-concepts/schemas) and the
[schema type reference](/reference/core/schema-types).

A `StagesSchema` has a stable string `id`, a positive integer `version`, and a
`nodes` array. Every structural feature is a node and every node can recursively
contain the others.

| Kind | Data shape | Children |
| --- | --- | --- |
| `field` | Value at its ID | Registered field type |
| `group` | Object at its ID | `nodes` |
| `collection` | Array at its ID | homogeneous `nodes` or discriminated `variants` |
| `wizard` | Object at its ID | ordered `stages`, each with recursive `nodes` |

```ts
const schema = {
  id: "checkout",
  version: 3,
  nodes: [{
    kind: "wizard",
    id: "flow",
    stages: [{
      id: "shipping",
      nodes: [{
        kind: "collection",
        id: "addresses",
        itemKey: address => address.id,
        nodes: [{ kind: "field", id: "city", type: "text" }],
      }],
    }],
  }],
} as const satisfies StagesSchema<Checkout, typeof fields>;
```

Structural IDs add object segments to the data path. Collection rows add their
current numeric index; stages add their ID. The corresponding node address uses
`{ kind: "row", id }` for stable row identity, so interaction metadata survives
reordering even though data indexes change.

## Initial values

The owner-provided canonical value is never populated implicitly. A registry
definition's `initialValue` is used as a field snapshot's baseline fallback
when that baseline path is `undefined`, and while core constructs defaults for
a new collection row. It may be a value or factory; use a factory for fresh
object or array defaults. Structural containers otherwise come from the
supplied domain value. Malformed collection or union shapes become diagnostics
rather than unchecked exceptions.

## Identity rules

Sibling IDs must be unique and safe. A dynamic replacement may retain identity
only when its kind and field type remain compatible. Reusing an address for an
incompatible node is diagnosed and its stale interaction state is discarded.

## Evaluation without a controller

`evaluateSchema({ schema, value, context, meta, fields, collectionKeys? })`
returns normalized nodes and diagnostics. `initialFieldValue(definition)`
evaluates a registry default. These lower-level exports are useful for tooling,
schema editors, and static analysis; applications normally use `stages()`. See
the [schema utility reference](/reference/core/schema-utilities) for exact
options, output, and failures.
