# DOM adapter

`@stages/dom` is a dependency-free browser adapter and accessible native-field
reference. It recursively renders a controller snapshot into an existing
element; it is intentionally not a layout or component library.

Start with [mounting and lifecycle](/adapters/dom/mounting), then choose the
[native fields](/adapters/dom/native-fields) or implement
[custom views](/adapters/dom/custom-views). The focused guides cover
[focus behavior](/adapters/dom/focus) and
[accessibility](/adapters/dom/accessibility). See the
[DOM API reference](/reference/dom) for every export.
