# React adapter

`@stages/react` connects the framework-neutral controller to application-owned
React components. It supplies lifecycle and binding primitives, not a visual
component library.

<StagesDemo example="controlled" />

Start with [lifecycle and ownership](/adapters/react/lifecycle), then implement
[field views](/adapters/react/fields). Collections, wizards, accessibility, and
performance each have a focused guide. The exact public surface is in the
[React API reference](/reference/react).
