# React adapter

`@stages/react` connects controller lifecycle and narrow snapshot subscriptions
to application-owned components. It does not prescribe layout or styling.

## Field views

A registered React view receives `id`, the full field snapshot, resolved
`props`, and `emit(name, payload?)`. Associate the ID with the control, honor
disabled state, and render `visibleIssues` with accessible relationships.

```tsx
function TextField({ id, field, props, emit }: ReactFieldProps<string, Props>) {
  return <label htmlFor={id}>
    {props.label}
    <input id={id} disabled={field.state.disabled} value={field.value}
      onFocus={() => emit("focus")} onBlur={() => emit("blur")}
      onChange={event => emit("input", event.target.value)} />
  </label>;
}
```

`StagesField` selects the requested path and renders its registered view. Its
generated ID is collision-safe across nested collection rows; pass `id` to
override it. Missing paths or views throw early.

## Hooks

| Hook | Use |
| --- | --- |
| `useStages(factory, input)` | Creates one controller, pushes controlled updates, subscribes, and destroys safely after real unmount. |
| `useStagesController(controller)` | Subscribes to the complete snapshot. |
| `useStagesField(controller, path)` | Narrowly subscribes to one field snapshot. |
| `useStagesCollection(controller, path)` | Returns stable keyed items, paths, capabilities, add/remove/move commands. |
| `useStagesWizard(controller, path)` | Returns stage state/capabilities and previous/next/go commands. |

`useStages` is safe under React Strict Mode effect replay. Keep schema, context,
and extension object identities stable with module constants or `useMemo` when
they have not semantically changed.

```tsx
const { controller, snapshot } = useStages(
  () => stages({ schema, fields, value, onChange: c => setValue(c.value) }),
  { value, context, schema },
);
```

React owns form tags, buttons, inactive-stage mounting, error summaries, focus,
and design-system integration. Use `snapshot.validation` for form-level status
and adapter hooks for collection/wizard controls.
