# React adapter

`@stages/react` manages controller lifecycle and connects snapshot fields to
application-owned React components.

```tsx
import { useState } from "react";
import { stages } from "@stages/core";
import { StagesField, useStages } from "@stages/react";

function ProfileForm() {
  const [value, setValue] = useState({ name: "" });
  const { controller, snapshot } = useStages(
    () => stages({
      schema,
      fields,
      value,
      onChange: ({ value }) => setValue(value),
    }),
    { value },
  );

  return (
    <form>
      <StagesField controller={controller} path={["name"]} />
      <output>{snapshot.validation.status}</output>
    </form>
  );
}
```

A registry field view receives `id`, the field snapshot, resolved `props`, and
an `emit(name, payload)` function. `useStagesCollection()` supplies typed stable
row operations, while `useStagesWizard()` supplies stage state and navigation
commands. Layout, action placement, error markup, and inactive-stage mounting
remain application decisions.

Controller teardown is safe under React Strict Mode effect replay.
