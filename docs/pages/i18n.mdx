# Internationalization

Localized copy belongs in field props and application-owned markup. Pass the
active locale and message catalog as controller context, then derive props from
that context.

```ts
const schema = {
  id: "profile",
  version: 1,
  nodes: [{
    kind: "field",
    id: "name",
    type: "text",
    deriveProps: ({ context }) => ({
      label: context.messages.nameLabel,
      placeholder: context.messages.namePlaceholder,
    }),
    validators: [{
      id: "name.required",
      on: ["input", "submit"],
      revealOn: ["blur", "submit"],
      validate({ fieldValue, path, context }) {
        return fieldValue
          ? []
          : [{
              id: "name.required",
              code: "required",
              message: context.messages.nameRequired,
              path,
              severity: "error",
            }];
      },
    }],
  }],
};

controller.update({
  context: {
    locale: "de-CH",
    messages: germanMessages,
  },
});
```

Changing context reevaluates dynamic schema behavior without changing the
controlled domain value. Date, number, and option formatting remains a view or
application concern.
