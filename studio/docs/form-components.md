# Studio form components

The v1 Insert panel includes Text, Text area, Number, Choice, Checkbox, Date,
Email, Phone, Website, Password, Time, and Slider. The Component gallery demo
provides example values for the newer controls. Open it as a new project from
the demo selector.

Email, Phone, Website, Password, and Time keep string values. Slider keeps a
number and offers minimum, maximum, and step settings. These fields use native
browser inputs; add Studio validators when values need validation. Password
masks the displayed input; its value follows the same scenario and persistence
rules as other text fields.

Choice's Options editor provides one editable row per option, with add, remove,
and move controls. Option text is also the stored answer value. Blank or duplicate
options remain drafts until corrected. Removing an option does not rewrite an
existing answer; select a new answer in Preview as needed. Existing newline-based
options remain compatible, and documents keep that format. Undo and redo cover
option edits and list operations.

Checkboxes use compact inline controls in both Design and Preview. The checkbox
label remains clickable and Space toggles the focused control. The desktop,
tablet, and mobile switches apply to every field type.
